# SkyBook

A front-end flight search and booking demo built with HTML, CSS, and JavaScript. Users can search flights between cities, browse mock results, and complete a mock booking through a modal form. Built for learning purposes, not a real booking platform.

## Features
- Flight search form (from, to, date, passengers)
- Dynamic results rendered with JavaScript from mock flight data
- Booking confirmation modal with passenger name entry
- Popular destinations section
- Why-choose-us section
- Current offers section
- FAQ section
- Fully responsive layout

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox)
- JavaScript (DOM manipulation, event handling, array methods)

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser

No installation, build steps, or backend required.
